# Project Memory Template

Read this reference when creating or updating `创作档案/创作记忆.txt`. Keep the file compact. It is the first recovery file to read when conversation context is limited.

## Update Rules

1. Update after drafting, revision, outlining, retcon, or user feedback that affects future writing.
2. Keep older plot material summarized by arc.
3. Keep only recent chapter summaries in detail.
4. Record user feedback as normalized rules. Use statuses: `active`, `pending`, `replaced`.
5. Prefer the newest explicit user instruction when rules conflict.
6. Do not copy full prose into this file.
